# Masterclass — L'intelligence artificielle à votre service

Présentation Slidev : *Du chat IA aux agents autonomes — transformer chaque étape du parcours client.*

Renée Costes — 2026

## Démarrage

```sh
bun install
bun run dev
```

Ouvre http://localhost:3030.

## Commandes

| Commande          | Description                                     |
| ----------------- | ----------------------------------------------- |
| `bun run dev`     | Lance le serveur de développement Slidev       |
| `bun run build`   | Génère la version statique dans `dist/`         |
| `bun run export`  | Exporte la présentation en PDF                  |

L'export PDF nécessite Playwright : `bun add -d playwright-chromium`.
